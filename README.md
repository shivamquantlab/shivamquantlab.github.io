# ShivamQuantLab Portfolio

Live portfolio: [shivamquantlab.github.io](https://shivamquantlab.github.io)

This repository contains the responsive GitHub Pages portfolio for Shivam Malik. It highlights four earlier statistical computing projects and **11 independent quantitative research projects**. The account currently has **17 public repositories** in total.

## Research data and interpretation

Trading research and experiments use synthetic data only. The point-in-time data project demonstrates availability logic with hand-authored records. No displayed chart, metric, or result represents real market performance or evidence of real investment returns.

## Deployment

GitHub Pages serves the site from the `main` branch. The portfolio is a static `index.html` page with inline styles and scripts; no build step or secret credentials are required.
